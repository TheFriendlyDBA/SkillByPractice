\# SQL Server DBA Practice Scripts — Learn by Doing



Welcome! This repository contains a curated collection of SQL Server scripts designed to help DBAs practice real-world troubleshooting in a safe lab or test environment. These scripts intentionally reproduce common (and not-so-common) issues so you can sharpen your diagnostic and problem‑solving skills through hands‑on experience.



\## 🎯 Purpose

The goal of this project is simple: \*\*learn by doing\*\*.

Instead of reading about SQL Server problems, you’ll recreate them, break things safely, and fix them — just like in real production scenarios.



\## 🧩 What’s Included

\- Scripts that simulate performance issues

\- Scripts that generate blocking, deadlocks, and waits

\- Scripts that create configuration mistakes

\- Scripts that mimic storage, memory, and CPU bottlenecks

\- Scripts for corruption scenarios (where safe and appropriate)

\- Solutions, explanations, and troubleshooting guidance



\## 🛠 How to Use

1\. Set up a \*\*lab or test SQL Server instance\*\* (never run these in production).

2\. Run the scripts to reproduce specific issues.

3\. Use your preferred tools — DMVs, Extended Events, Query Store, PerfMon, etc. — to diagnose the problem.

4\. Review the included solutions to compare your approach.
